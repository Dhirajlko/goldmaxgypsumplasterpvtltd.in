# Goldmax Gypsum Plaster Pvt. Ltd. (goldmaxgypsumplasterpvtltd.in)

Official responsive web application and digital presence for **Goldmax Gypsum Plaster Pvt. Ltd.** (Goldmax Plasters Private Limited) — India's premier manufacturer and distributor of high-performance one-coat gypsum plasters, chemical bonding agents, superfine Plaster of Paris (POP), and architectural wall finishing solutions.

---

## 🌟 Key Features

1. **Smart Gypsum Plaster & Cost Estimator:**
   * Interactive calculator estimating total 25kg bags, metric tonnes, estimated cost, water savings (liters), and structural dead-load reduction based on area, thickness, and masonry substrate.
   * Direct transfer to official quote inquiry form with pre-populated values.

2. **Interactive Wall Finish Comparison Slider:**
   * Visual Before/After slider contrasting conventional coarse sand-cement plaster against Goldmax mirror-smooth ivory gypsum finish.

3. **Engineered Product Portfolio:**
   * Category filter tabs (*All, Gypsum Plaster, Bonding Agents, POP & Putty, Boards & Accessories*).
   * Detailed Technical Data Sheet (TDS) modal popups with IS 2547 specifications, compressive strength, setting times, and coverage tables.

4. **5-Step Standardized Application Methodology:**
   * Complete site guide covering surface preparation, Goldmax Bond-It keying, scientific water mixing, single-coat application, and trowel polishing.

5. **Lead Generation & WhatsApp Connect:**
   * Validation-enabled quote request form.
   * Direct 1-click WhatsApp customer care connect (`+91 98765 43210`).
   * Floating quick-dial, WhatsApp, and Back-to-Top controls.

## 🚀 How to Run Locally

No build tools or external servers required:
1. Clone the repository:
   ```bash
   git clone https://github.com/Dhirajlko/goldmaxgypsumplasterpvtltd.in.git
   ```
2. Open `index.html` directly in any modern browser (Chrome, Edge, Firefox, Safari).
